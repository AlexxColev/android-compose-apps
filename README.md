A portfolio of native Android applications built with **Kotlin** and **Jetpack Compose** as part of Mobile Application Programming coursework at the Academy of Economic Studies of Moldova (ASEM).

## Included Projects

* **`MyNewHouse/` — House Construction Stage Tracker**
  * Interactive mobile checklist and progress tracker for managing residential construction phases using Jetpack Compose state management and Material 3 components.
* **`RegistrulGrupei/` — Course & Group Registry App**
  * Dynamic list management application supporting real-time sorting (by name/credits), filtering, and item deletion using reactive Compose state (`remember`, `mutableStateListOf`).
* **`lab_2_android/` — Interactive UI & State Lab**
  * Multi-component Compose layout demonstrating user input handling, state hoisting, and event callbacks.
* **`HappyBirthday/` & `primul_project/` — Compose Layout Fundamentals**
  * Foundational Android Studio projects exploring `Column`, `Row`, `Box`, typography, and resource management.

## Tech Stack

* **Language:** Kotlin
* **UI Toolkit:** Jetpack Compose (Material 3)
* **Build & Tools:** Android Studio, Gradle (Kotlin DSL), Git
