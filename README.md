# Android Mobile Applications (Kotlin & Jetpack Compose)

Native Android applications developed using **Kotlin** and **Jetpack Compose** as part of Mobile Application Programming coursework at the Academy of Economic Studies of Moldova (ASEM).

## Features & Architecture
* **Declarative UI:** Built with Jetpack Compose, Material 3 components, state hoisting, and reactive UI updates (`remember`, `mutableStateOf`).
* **Data Management:** Interactive lists with dynamic sorting, filtering, and item deletion.
* **Clean Architecture Principles:** Separation of UI state and domain models in Kotlin.

## Tech Stack
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Tools:** Android Studio, Gradle, Git
